Welkom op de website

Op deze website leer je hoe je zelf een website maakt met HTML en CSS en hoe je deze gratis online zet met GitHub Pages.

HTML bepaalt de inhoud van je website. CSS zorgt ervoor dat je website er mooi uitziet. GitHub Pages maakt het mogelijk om je website online te publiceren.

💡 Tip: werk stap voor stap en sla je code regelmatig op.

1. GitHub-account aanmaken

Ga naar GitHub en maak een account aan. Kies een goede gebruikersnaam, want die verschijnt in het webadres van je website.

Maak een account aan

Verifieer je e-mailadres en bewaar je inloggegevens veilig.

Meer uitleg vind je in de officiële GitHub Pages-handleiding .

2. Een repository aanmaken

Een repository is een online opslagplaats voor alle bestanden van je website.

  1. Log in op GitHub.
  2. Klik rechtsboven op het plusteken.
  3. Kies New repository.
  4. Geef de repository de naam jouwgebruikersnaam.github.io.
  5. Kies Public.
  6. Vink aan dat een README-bestand wordt aangemaakt.
  7. Klik op Create repository.
Let op! Vervang jouwgebruikersnaam door je eigen GitHub-gebruikersnaam. De naam moet precies kloppen.

3. Je eerste HTML-pagina

Maak in je repository een nieuw bestand met de naam index.html. Dit is de homepage van je website.

Een eenvoudige HTML-pagina ziet er zo uit:

<!DOCTYPE html>
<html lang="nl">
<head>
    <meta charset="UTF-8">
    <meta name="viewport" content="width=device-width, initial-scale=1.0">
    <title>Mijn website</title>
</head>
<body>
    <h1>Welkom op mijn website!</h1>
    <p>Dit is mijn eerste webpagina.</p>
</body>
</html>

Wat betekenen de onderdelen?

  • html: bevat de volledige webpagina.
  • head: bevat informatie over de pagina.
  • title: bepaalt de titel op het browsertabblad.
  • body: bevat de zichtbare inhoud.
  • h1: maakt een grote kop.
  • p: maakt een alinea.

Sla het bestand op met Commit changes.

4. Een tweede pagina en links toevoegen

Maak naast index.html bijvoorbeeld binairstelsel.html en kleurmodellen.html.

Met een link open je een andere pagina:

<a href="binairstelsel.html">
    Lees over het binaire stelsel
</a>

Een link terug naar de homepage:

<a href="index.html">
    Terug naar de homepage
</a>

Het element a maakt een link. Het attribuut href bepaalt waar de link naartoe gaat.

Tip: gebruik duidelijke linkteksten, zodat bezoekers weten waarop ze klikken.

5. Een afbeelding toevoegen

Upload eerst een afbeelding naar je GitHub-repository. Klik op Add file en daarna op Upload files.

Je kunt de afbeelding vervolgens zo invoegen:

<img src="afbeeldingen/voorbeeld.jpg"
     alt="Beschrijving van de afbeelding">
  • img betekent afbeelding.
  • src geeft de locatie van de afbeelding aan.
  • alt geeft een tekstuele beschrijving.

De naam en extensie van de afbeelding moeten exact overeenkomen met het bestand in je repository.

Tip: zet afbeeldingen bij elkaar in een map met de naam afbeeldingen.

6. Een navigatiemenu maken

Een menu bestaat uit een lijst met links. Hierdoor kunnen bezoekers gemakkelijk door je website navigeren. 

<nav>
    <ul>
        <li><a href="index.html">Home</a></li>
        <li><a href="binairstelsel.html">Binaire stelsel</a></li>
        <li><a href="kleurmodellen.html">Kleurmodellen</a></li>
    </ul>
</nav>
  • ul maakt een ongeordende lijst.
  • li maakt een lijstitem.
  • a maakt een link.

Plaats dezelfde navigatie op iedere pagina van je website.

7. Je website opmaken met CSS

HTML bepaalt de structuur en inhoud. CSS bepaalt onder andere de kleuren, lettertypes, afstanden en achtergronden.

Hier is een voorbeeld van CSS:

body {
    font-family: Arial, sans-serif;
    background-color: #f2f5fb;
    color: #202b3c;
    line-height: 1.7;
}

h1 {
    color: #304bd0;
    text-align: center;
}

p {
    font-size: 16px;
}

a {
    color: #4968f2;
    text-decoration: none;
}

a:hover {
    text-decoration: underline;
}

Een apart CSS-bestand gebruiken

Maak een bestand met de naam opmaak.css. Zet de CSS-code daarin.

Voeg vervolgens deze regel toe binnen het element head van ieder HTML-bestand: 

<link rel="stylesheet" href="opmaak.css">

Belangrijke CSS-eigenschappen

Eigenschap Betekenis
color De kleur van de tekst.
background-color De achtergrondkleur.
padding Ruimte binnen een element.
margin Ruimte buiten een element.
display: block Het element begint op een nieuwe regel.
:hover De stijl wanneer je met de muis over een element gaat.
Let op: deze website heeft de CSS al in het HTML-bestand staan. Je hoeft dus geen tweede bestand te maken om dit ontwerp te gebruiken.

8. Bestanden organiseren

Wanneer je website groeit, is het handig om bestanden in mappen te organiseren. 

mijn-website/
├── index.html
├── binairstelsel.html
├── kleurmodellen.html
├── opmaak.css
└── afbeeldingen/
    └── voorbeeld.jpg

Laat index.html in de hoofdmap staan. Wanneer je bestanden in mappen zet, moet je in je links het juiste bestandspad gebruiken.

Samenwerken

Je kunt anderen uitnodigen om samen aan de website te werken. Open je repository, ga naar Settings en zoek Collaborators. Voeg daar de gebruikersnaam van de andere persoon toe.

9. Je website online zetten

Sla je wijzigingen op met Commit changes. Als je repository de juiste naam heeft, kun je je website openen via: 

https://jouwgebruikersnaam.github.io

Vervang jouwgebruikersnaam door je eigen GitHub-gebruikersnaam.

  1. Open je repository op GitHub.
  2. Ga naar Settings.
  3. Klik op Pages.
  4. Controleer of GitHub Pages is ingeschakeld.
  5. Wacht tot de website is gepubliceerd.
  6. Open de link van je website.
Werkt je website niet?
  • Controleer of het bestand index.html heet.
  • Controleer de naam van de repository.
  • Controleer of alle bestanden zijn opgeslagen.
  • Controleer of je bestandsnamen en links kloppen.
  • Wacht even en vernieuw de pagina.
